Sans e-mail, la limite gratuite est d'environ 5 000 caractères par jour, ce qui suffit pour quelques pages. Avec un e-mail, elle passe à environ 50 000 : utile pour traduire tout un chapitre.

Services externes (connexion requise) : la lecture du texte (OCR) utilise Tesseract.js, chargé depuis cdnjs avec ses données de langue ; la traduction utilise l'API gratuite MyMemory, qui reçoit le texte détecté et a une limite quotidienne. Ce n'est pas une IA générative : le résultat reste approximatif. Pour traduire une page : ouvre les réglages du lecteur (icône en haut du lecteur), puis « Traduire cette page ».

Sauvegarde des préférences

Les réglages, la progression de lecture et les marque-pages restent enregistrés dans ce navigateur. Exporte-les dans un fichier pour les restaurer ou les copier sur un autre appareil. La bibliothèque et les favoris se synchronisent via Google Drive (ci-dessous).

Synchronisation entre appareils (Google Drive)

Connecte un compte Google pour synchroniser la bibliothèque et les téléchargements entre tes appareils (iPhone, Android, ordinateur). Il faut d'abord créer, gratuitement, un « ID client OAuth » sur Google Cloud Console (type « Application Web », en autorisant l'adresse de cette page), puis le coller ci-dessous.

Autres façons d'ajouter

Lire via le navigateur

Tu as ouvert ce lecteur depuis un fichier local : le favori ne pourra pas te ramener ici. Mets d'abord ce fichier en ligne (GitHub Pages, Netlify), puis rouvre cette fenêtre depuis l'adresse web.

  1. Touche « Copier le code » ci-dessous.
  2. Dans Safari, touche le bouton Partager (le carré avec une flèche), puis « Ajouter un signet », et appelle-le « Envoyer au lecteur ».
  3. Ouvre tes signets (l'icône de livre), garde le doigt appuyé sur « Envoyer au lecteur », touche « Modifier », efface l'adresse, colle le code copié et enregistre.
  4. Va sur le site. Si une vérification apparaît, passe-la.
  5. Sur la page d'un manga : ouvre tes signets et touche « Envoyer au lecteur ». Le manga arrive ici avec ses chapitres.
  6. Pour lire un chapitre : touche-le ici, il s'ouvre dans le navigateur. Passe la vérification, descends jusqu'en bas pour charger toutes les images, puis touche « Envoyer au lecteur ». Le chapitre s'ouvre ici, prêt à être téléchargé.
  1. Touche « Copier le code » ci-dessous.
  2. Dans Chrome, ouvre n'importe quelle page, touche le menu ⋮ puis l'étoile pour l'ajouter aux favoris.
  3. Menu ⋮ → Favoris → touche ⋮ à côté du favori que tu viens d'ajouter → Modifier. Appelle-le « Envoyer au lecteur », efface l'adresse, colle le code copié et enregistre.
  4. Va sur le site. Si une vérification apparaît, passe-la.
  5. Sur la page d'un manga : touche la barre d'adresse, écris « Envoyer », puis touche la suggestion « Envoyer au lecteur » (avec l'icône de favori). N'appuie pas sur Entrée. Le manga arrive ici avec ses chapitres.
  6. Pour lire un chapitre : touche-le ici, il s'ouvre dans le navigateur. Passe la vérification, descends jusqu'en bas pour charger toutes les images, puis relance « Envoyer au lecteur » comme ci-dessus. Le chapitre s'ouvre ici, prêt à être téléchargé.

Un autre navigateur ? Le principe est le même : un favori dont l'adresse est le code, lancé depuis la barre d'adresse. Si ça ne marche pas, essaie avec Chrome (Android) ou Safari (iPhone).
